이 스킬은 VitePress 기반의 기술 블로그 포스트를 작성하고 관리하는 에이전트를 위한 지침을 제공합니다.

# 핵심 역량

1. **Frontmatter 자동 생성**: 
   - 모든 포스트 최상단에 `title`, `date`, `tags`가 포함된 YAML Frontmatter를 생성합니다.
   - `date`는 ISO 8601 형식(`YYYY-MM-DDTHH:mm:SS+09:00`)을 엄격히 준수합니다.

2. **구조화된 콘텐츠 작성**:
   - `<h1>`은 페이지당 단 하나만 사용합니다.
   - 계층적인 헤더 구조(`##`, `###`)를 사용하여 가독성을 높입니다.
   - 코드 블록에는 적절한 언어 명시(예: `bash`, `typescript`, `markdown`)를 포함합니다.

3. **SEO 및 메타데이터 지원**:
   - 포스트의 제목은 핵심 키워드를 포함하며 간결하게 작성합니다.
   - 필요 시 메타 설명을 위한 요약문을 서두에 배치합니다.

4. **커밋 메시지 규칙 준수**:
   - 변경 사항을 커밋할 때 메시지는 반드시 `title: [포스트 제목]` 형식을 유지합니다.

# 작업 절차

1. **분석**: 작성할 주제에 대한 핵심 정보를 수집하고 관련 기술 스택을 확인합니다.
2. **초안 작성**: 
   - `posts/` 디렉토리에 파일명을 지정하여 생성합니다 (예: `my-new-post.md`).
   - Frontmatter를 먼저 작성한 후 본문 내용을 구성합니다.
3. **검토**: 
   - 기술적 정확성, 맞춤법, 이미지/링크의 유효성을 확인합니다.
   - `pnpm l` 명령어로 로컬 서버에서 렌더링 결과가 올바른지 확인합니다.
4. **배포 준비**: 
   - `git add` 후 `title` 규칙에 맞춘 커밋 메시지로 커밋을 생성합니다.

# 스타일 가이드

- **언어**: 정중하고 전문적인 한국어 톤앤매너를 유지합니다.
- **코드**: 가급적 구체적인 예제 코드를 포함하며, 블로그 테마와 어울리도록 작성합니다.
- **이미지**: 필요한 경우 `generate_image` 도구를 사용하여 시각적 자료를 생성하고 `public/` 경로에 저장하여 참조합니다.
