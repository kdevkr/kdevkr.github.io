# Git 활용 지침

## 커밋 메시지 규칙

### 타입

세 가지만 사용합니다.

| 타입 | 범위 |
|---|---|
| `post` | 글 발행, 글 수정, 해당 글의 이미지 등 글 단위 변경 일체 |
| `site` | 테마(`.vitepress/theme/`), 설정(`config.mts`, 빌드, 배포), 의존성, 버그 수정, 공용 자산 |
| `docs` | 운영 문서 (`CLAUDE.md`, `AGENTS.md`, `.claude/rules/` 등) |

### 제목 줄

```
<type>: <한국어 요약>
```

- 타입은 소문자, 콜론 뒤 공백 1칸
- 요약은 한국어, **마침표 없이 명사형으로 종결** (`~추가`, `~수정`, `~개선`, `~삭제`)
- 길이 제한: **50자 이내**. 단, `post:`는 글 제목을 그대로 쓰기 위해 **면제**
- 글 발행 커밋은 요약을 글 제목 그대로 사용 (예: `post: 리눅스 프로세스를 안전하게 종료시키는 방법`)

### 본문 (선택)

다음 중 하나라도 해당하면 작성합니다.

- `site:` 변경에서 파일이 2개 이상
- 제목만으로 변경 의도가 드러나지 않을 때
- `post:`에서 글 본문 외 메타(태그, 날짜, 슬러그 등)를 함께 손댔을 때

형식:

```
<제목 줄>

- 변경점 1
- 변경점 2
```

- 제목과 본문 사이 빈 줄 1개
- 불릿(`-`)으로 한 줄당 한 가지

### 푸터 (필수)

모든 커밋에 다음 한 줄을 포함합니다.

```
🤖 Agent: <에이전트 이름> (<모델 ID>)
```

- 본문(또는 본문이 없으면 제목) 아래 빈 줄 1개 후 단 한 줄
- 에이전트 이름은 실제 사용한 것 그대로 (`claude-code`, `blog-writer`, `antigravity` 등)
- 모델 ID는 `claude-opus-4-7`, `claude-sonnet-4-6` 형식

### 예시

```
post: 청년도약계좌와 청년미래적금

🤖 Agent: blog-writer (claude-opus-4-7)
```

```
site: 사이드바 활성 항목 자동 스크롤 추가

- enhanceApp에서 onAfterRouteChange 훅 패치
- 활성 .VPLink 를 scrollIntoView로 가시화

🤖 Agent: claude-code (claude-opus-4-7)
```

```
docs: 커밋 메시지 규칙 추가

🤖 Agent: claude-code (claude-opus-4-7)
```
