# 문장 스타일 규칙

- **문장 호흡과 문단 구분**: 의미 단위의 간결한 문장으로 작성하되 너무 짧은 문장을 기계적으로 나열하지 않고 주제가 바뀌면 문단을 나눕니다.
- **자연스러운 전개**: 기계적인 두괄식·개조식을 피하고 상황과 생각의 흐름을 따릅니다.
- **접속사·상투구 배제**: 습관적 접속사(*또한, 따라서*)와 상투적 틀(`알아보겠습니다`, `마치며`)을 쓰지 않습니다.
- **불릿 목록 간결화**: 불릿 목록 항목에는 한 문장만 간결하게 작성합니다.
- **일상적인 표현 사용**: 인위적이거나 과장된 문구 대신 자연스러운 일상 어휘로 작성합니다.

| 구분 | 지양 표현 / 패턴 |
| --- | --- |
| **자문자답·전환** | `그래서 어떻게 됐나`, `그리고 하나 더.`, `왜 지금 이것인가`, `핵심은 여기에 있다` |
| **대조·대구** | `주로 X가 아니라 Y였다.`, `A에는 없는 게 B에는 있다.`, `A는 B지 C의 근거가 아닙니다.` |
| **과장·관용구** | `이게 C의 전부다.`, `~판이다`, `~에 걸쳐있다`, `~로 못 박는다` |
| **특수문자·서식** | Em Dash(`—`, `——`), 과도한 굵은 글씨 (필요 시 쉼표나 단문 분리 고려) |

- **인라인 링크**: 참고자료 절 없이 본문 문맥에 직접 링크합니다.
