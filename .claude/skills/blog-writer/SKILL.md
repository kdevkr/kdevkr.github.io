이 스킬은 실무 기술 경험과 노하우를 **VitePress** 기반의 기술 블로그(`kdevkr.github.io`) 콘텐츠로 기록하고 관리하는 작업을 지원합니다. 고품질의 기술 문서를 작성하고, 실전 사례 중심의 지식을 효과적으로 전달하는 데 도움을 드립니다.

# 언제 사용하나요?

- **새로운 기술 포스트 작성**: 새로운 주제로 블로그 글을 처음부터 작성하고자 할 때 사용하세요.
- **기존 콘텐츠 수정 및 업데이트**: 이미 게시된 글의 오타를 수정하거나 새로운 정보를 반영할 때 유용합니다.
- **블로그 메타데이터(Frontmatter) 관리**: 글의 제목, 날짜, 태그 등 YAML 설정을 올바르게 구성해야 할 때 사용하세요.
- **이미지 생성 및 배치**: `generate_image` 도구를 사용하여 글에 필요한 시각 자료를 추가할 때 활용하세요.

# 핵심 지침

1. **엄격한 Frontmatter 준수**:
   - 모든 마크다운 파일 최상단에 `title`, `date`, `tags`가 포함된 YAML 형식을 반드시 생성해 주세요.
   - 특히 `date` 필드는 ISO 8601 형식(`YYYY-MM-DDTHH:mm+09:00`)을 엄격히 따라야 합니다.
   
2. **콘텐츠 구조화**:
   - 페이지당 단 하나의 `<h1>` 헤더만 사용하며, 하위 주제는 `##`, `###` 등으로 계층을 나누어 가독성을 높여주세요.
   - 코드 블록에는 항상 해당 언어(예: `typescript`, `go`, `yaml`)를 명시해 주세요.

3. **SEO 최적화**:
   - 제목은 핵심 키워드를 포함하며 간결하게 작성해 주세요.
   - 도입부에는 글의 내용을 요약한 1~2문장을 배치하여 검색 엔진과 독자의 이해를 도와주세요.

4. **커밋 메시지 제안 규칙**:
   - 블로그 작업이 완료되면 직접 커밋하지 않고, 다음과 같은 양식으로 적절한 커밋 메시지를 구성하여 사용자에게 제안해 주세요:
     ```text
     title: [포스트 제목]

     - 주요 내용 1
     - 주요 내용 2
     - 주요 내용 3
     ```

# 작업 절차

1. **주제 분석 및 정보 수집**: 작성할 주제의 핵심 내용을 파악하고 참고할 수 있는 기술 스택을 확인하세요.
2. **초안 생성**: 
   - `resources/draft.md` 템플릿을 참고하여 마크다운 파일을 생성해 주세요.
   - `posts` 디렉토리에 주제를 잘 나타내는 영문 파일명으로 생성합니다 (예: `posts/my-new-tech-post.md`).
   - 파일 생성 직후 바로 Frontmatter를 작성하세요.
3. **본문 작성 및 시각화**:
   - 준비된 내용을 정중한 한국어 경어로 작성하세요.
   - 상세한 구조와 규칙은 [style-guide.md](./resources/style-guide.md)를 준수해야 합니다.
   - 필요한 이미지는 `generate_image`를 통해 생성하고 **`public/images/posts/[포스트파일명]`** 디렉토리에 **`001`, `002`...** 와 같이 순차적으로 파일명을 지정하여 저장한 뒤 참조하세요.
4. **마크다운 양식 검증**: 
   - `scripts/validate_post.py` 스크립트를 실행하여 생성된 포스트의 Frontmatter, 헤더 구조, 코드 블록 언어 명시 여부를 자동으로 확인하세요.
   - 실행 예: `python .agents/skills/bloger/scripts/validate_post.py posts/my-new-post.md`
5. **완료 및 커밋 메시지 제안**:
   - 검증이 통과되었다면 정해진 규칙에 따라 커밋 메시지를 구성하여 사용자에게 제안하세요. 
   - **주의**: 에이전트는 직접 `git commit`을 수행하지 않습니다. 사용자가 직접 내용을 검토하고 커밋할 수 있도록 안내해 주세요.

# 스타일 가이드

- **상세 스타일 가이드**: 더 자세한 규칙은 [style-guide.md](./resources/style-guide.md) 파일을 참조해 주세요.
- **포스트 초안 템플릿**: 표준화된 구성을 위해 [draft.md](./resources/draft.md) 파일을 활용해 주세요.
- **말투**: 항상 정중하고 친절한 한국어 경어(~입니다, ~해요 등)를 사용해 주세요.
- **내용**: 단순한 정보 전달을 넘어, 독자가 실습하거나 이해하기 쉬운 구체적인 예제 코드를 포함하는 것이 좋습니다.
- **품질**: 맞춤법 검사를 철저히 하고, 문장이 매끄럽게 읽히는지 다시 한번 검토해 주세요.
