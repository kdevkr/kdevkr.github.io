  • AWS Aurora PostgreSQL에 PGMQ 확장 설치하기 (2026년 5월 20일)

    AWS Aurora 및 RDS PostgreSQL 환경에서 pg_tle 방식을 사용하여 PGMQ(Postgres Message Queue)를 설치하고 활용하는 방법을 가이드합니다.

  • Grafana 기본 로그인 폼 숨기기 (2026년 5월 17일)

    기본 로그인 폼을 숨기고 구글 로그인 버튼만 표시하는 방법을 알아보고 우회하는 경로도 소개합니다

  • AWS 웹 콘솔 로그인 시 기본 리전 (2026년 5월 17일)

    웹 콘솔 로그인 시 다른 리전으로 이동된다면 자주 사용하는 리전을 고정하는 것을 알아봅니다.

  • 대용량 이력 테이블(History Table) 파티셔닝 전략 (2026년 5월 13일)

    PostgreSQL에서 pg_partman과 pg_cron을 활용하여 대용량 이력 테이블을 효율적으로 파티셔닝하고 관리하는 전략을 소개합니다.

  • 알림 수신 시간대 설정해보기 (2026년 5월 8일)

    알림 수신 요일·시간대 설정 기능을 구현하며 마주친 비트마스크 표현, 한국 달력의 일요일 시작 관행, 라이브러리·표준별 DayOfWeek 차이를 정리합니다.

  • Tailscale VPN 으로 로컬 환경에 접근하기 (2026년 5월 1일)

    Tailscale 을 사용해 외부 기기에서 로컬 개발 서버에 접근하고, VitePress 의 호스트 차단 정책까지 함께 푸는 방법을 정리합니다.

  • GitHub Actions Node.js 20 지원 종료 대응 (2026년 5월 1일)

    GitHub Actions 러너의 Node.js 20 지원이 2026-06-02부터 강제 종료됩니다. 블로그 워크플로우의 액션과 런타임을 정비하며 알게 된 점들을 정리합니다.

  • 비트마스크를 활용한 설비 디바이스 Fault 처리 (2026년 4월 30일)

    산업 설비의 결함·경고 상태를 16비트 정수로 압축해 효율적으로 처리하는 방법을 비트마스크, Java BitSet, kdb+/q 예시로 정리합니다.

  • 리눅스 프로세스를 안전하게 종료시키는 방법 (2026년 4월 25일)

    빈 변수와 `pgrep -f`가 만나 서버의 모든 프로세스를 종료시킨 사고를 복기하고, lsof·ss·fuser와 SIGTERM 기반 안전한 프로세스 종료 패턴을 정리합니다.

  • Antigravity 에게 깃허브 권한 주기 (2026년 4월 25일)

    코딩 에이전트가 GitHub 이슈와 PR을 다루도록 권한을 설정할 때 마주치는 MCP Server와 GitHub CLI의 트레이드오프, Fine-grained PAT 스코프 설정을 정리합니다.

  • 개인 PC에서 조직 깃허브 계정 활용하기 (2026년 4월 25일)

    개인 PC에서 개인과 조직 GitHub 계정을 동시에 쓰며 빠르게 전환할 수 있도록 `gh`의 다중 로그인과 프로젝트별 Git 환경 구성 방법을 정리합니다.

  • AI 토큰 사용량 누수 (2026년 4월 24일)

    AI 코딩 에이전트가 토큰을 빠르게 소진시키는 원인을 명령어 실패·컨텍스트 유실·출력 과대 관점에서 분석하고 PATH 환경변수 설정으로 누수를 줄이는 방법을 정리합니다.

  • Antigravity 에서 AWS Aurora Postgres 에 접근하기 (2026년 3월 27일)

    AI 에이전트 Antigravity에서 AWS Aurora PostgreSQL에 IAM 인증으로 접근해 스키마 조회와 쿼리 검증을 안전하게 수행하기 위한 환경 구성을 정리합니다.

  • 브라우저 PDF 생성 시 텍스트 밀림 현상 (2026년 2월 19일)
