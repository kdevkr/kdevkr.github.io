# 무료 할당량을 제공하는 Agentic IDE

대표적인 코딩 에이전트를 지원하는 [Claude Code](https://www.claude.com/product/claude-code) 또는 [Cursor](https://cursor.com/) 는 무료 할당량을 지원하지 않아요. 조직에서 AI 코딩 에이전트에 대한 비용을 복지로 지원하지 않거나 AI 에 대한 비용이 부담스러운 개발자들을 위해 무료 할당량을 제공하는 에이전트 또는 에이전틱 IDE를 찾아보았어요.

## Github Copilot

[깃허브 코파일럿](https://github.com/features/copilot?locale=ko-KR)은 Jetbrains IDE 또는 VSCode 와 같은 에디터에서 사용할 수 있도록 확장 플러그인을 지원하면서도 ==매월 50회의 에이전트 모드 및 채팅 요청이 가능한== Free 요금제를 지원해요.

> Github Copilot 프리뷰 기능을 활성화하면 [Raptor Mini](https://github.blog/changelog/2025-11-10-raptor-mini-is-rolling-out-in-public-preview-for-github-copilot/) 모델을 사용해볼 수 있어요.

## AWS Kiro

[Kiro](https://kiro.dev/)는 AWS에서 제공하는 VSCode 기반의 에이전틱 IDE로 ==월간 50 크레딧을 지원==해요. 그리고 소셜 로그인 또는 Builder ID 를 사용하면 [최초 30일 간 이용할 수 있는 500 크레딧을 보너스로](https://kiro.dev/pricing/) 제공해줘요.

## Gemini CLI

[Gemini CLI](https://geminicli.com/)는 Gemini Code Assist 기준 내에서 ==일간 무료 할당량을 지원==하고 있어요. 단, Google Antigravity 와 플랫폼 할당량을 공유하기 때문에 Google Antigravity 에서 할당량을 모두 소진했다면 일간 무료 할당량을 이용할 수 없어요.

## Junie Pro

JetBrains의 AI 코딩 에이전트인 Junie Pro 는 무료 요금제가 없지만 ==All Products Pack 구독인 경우== AI Assistant 와 Junie 를 사용할 수 있는 AI Pro 요금제가 기본적으로 포함되어요. 현재 조직은 인텔리제이에 대한 라이센스 구독을 지원하고 있었기 때문에 AI Pro 요금제에서 제공해주는 ==월간 20 AI 크레딧==을 사용할 수 있어요.

## Google Antigravity

구글이 Windsurf 인력을 영입하고나서 ==VSCode 기반의 에이전틱 IDE로 공개==했어요. 2025년 12월 5일 기준으로 [Google One 기반의 개발자 플랜이 적용되어](https://blog.google/feed/new-antigravity-rate-limits-pro-ultra-subsribers/) 기존 무료 요금제는 주간 할당량을 제공해요. [Google One](https://one.google.com/ai)의 Pro 요금제는 월 29,000원으로 [Cursor IDE](https://cursor.com/pricing)와 비교해서 많이 저렴하지만 개발자 플랜마저도 일부  할당량이 제공되고 ==매 5시간마다 초기화== 됩니다.

> Gemini CLI 와 Gemini Code Assist 와 함께 무료 할당량이 공유됩니다.

## 끝으로

이렇게 무료 할당량을 지원하는 AI 코딩 에이전트들을 살펴봤어요. AI 코딩 에이전트에서 제공해주는 무료 할당량은 프로젝트 코드 베이스에 따라 금방 소진되기 때문에 유료 요금제를 유도하는 걸 느낄 수 있을거에요. 그리고 Antigravity 는 구글 계정 기반이므로 조직 워크스페이스 계정과 개인 계정을 나누어서 사용할 수도 있겠네요.
